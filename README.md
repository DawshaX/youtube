# 🌌 CosmicTube Engine - القناة الكونية رقم 1 عالمياً

منظومة ذكية متكاملة لإدارة وبناء قناة يوتيوب تنافس على المركز الأول عالمياً، مستوحاة من معادلات أكبر القنوات والمشاهير في العالم (مثل MrBeast، Kurzgesagt، Zach King)، مع ربط مباشر بـ **Google YouTube Data API v3** للبحث الذكي والنشر التلقائي.

---

## 🚀 المميزات الرئيسية للمنظومة

### 1. 🌍 رادار الفيديوهات الفيروسية (Global Viral Spy & Trends)
- رصد وتحليل الفيديوهات الأكثر مشاهدة وانتشاراً حول العالم لحظياً.
- فلاتر جغرافية (Global, US, Egypt & Middle East, India, Brazil, Japan, UK).
- فلاتر تصنيفية (تحديات MrBeast، غرائب العلوم والكون، خدع بصرية صامتة، تجارب كبرى، شورتس).
- **تشريح الـ DNA الفيروسي (Viral DNA Breakdown)**: تحليل سر خطاف الـ 3 ثواني الأولى ومعدل سرعة الانتشار (Velocity).
- زر **"استنساخ الفكرة"** لنقل الفكرة مباشرة إلى استوديو السيناريو بضغطة زر واحدة.

### 2. 🎬 استوديو السيناريو والمحتوى الكوني (Viral Script & Storyboard Studio)
- **5 عناوين خارقة لمعدل النقر (High-CTR Title Formulas)** مع مؤشر نسبة النقر المتوقعة.
- **مخطط الاحتفاظ بالجمهور الزمني (Retention Timeline Storyboard)**:
  - `0:00 - 0:03`: الخطاف البصري الصاعق (The 3-Second Hook) دون أي مقدمة مملة.
  - `0:04 - 0:18`: القواعد والرهان المستحيل.
  - `0:19 - 0:50`: الصدمة الأولى والتصعيد السريع.
  - `0:51 - 1:45`: المنعطف غير المتوقع (Mid-Video Twist).
  - `1:46 - النهاية`: الذروة ودعوة الاشتراك السريعة (Zero-Drop Payoff).
- **3 مفاهيم للصور المصغرة (Thumbnail Blueprints)** عالية التباين والجاذبية.
- **حزمة اللغات العالمية (Multi-Language Global Pack)**: عناوين وأوصاف مترجمة فوراً لـ 8 لغات عالمية (العربية، الإنجليزية، الإسبانية، الهندية، البرتغالية، الفرنسية، اليابانية، الألمانية).

### 3. 🚀 مركز النشر والرفع المباشر (Smart Publisher & Uploader)
- رفع ملفات الفيديو والصور المصغرة مباشرة.
- محاكاة فورية لشكل الفيديو كما يظهر للمشاهدين على يوتيوب (Feed Preview).
- دعم رفع الفيديوهات الطويلة والـ YouTube Shorts (`#Shorts`).
- نشر مباشر على قناتك عبر YouTube Data API v3 (`videos.insert`) مع تحديد الخصوصية (علني، غير مدرج، خاص).
- قائمة بالفيديوهات المنشورة مع روابط المشاهدة.

### 4. #️⃣ مولد الهاشتاجات وسيو يوتيوب (Tags & SEO Dominator)
- استخراج أفضل 30 كلمة مفتاحية (Tags) موزعة بين الكلمات الشائعة والكلمات المحددة ومحفزات الخوارزمية.
- استخراج أقوى 10 هاشتاجات ترند.
- زر نسخ مباشر بضغطة واحدة متوافق مع خانة الوسوم في YouTube Studio.

### 5. ⚙️ مركز ربط القناة والـ API (YouTube Connect Hub)
- دليل تفاعلي مفصل خطوة بخطوة بالصور التوضيحية للحصول على المفاتيح من **Google Cloud Console**.
- خانات آمنة لإدخال **Google API Key** للبحث و **OAuth 2.0 Client ID / Secret** لرفع الفيديوهات.
- زر تفويض فوري بحساب Google لنقل الصلاحيات ومزامنة القناة.

## 🔑 كيفية تفعيل وربط الـ YouTube API

### أ) مفتاح البحث والترندات (API Key):
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com).
2. أنشئ مشروعاً جديداً (مثلاً: `CosmicTube`).
3. من القائمة: **APIs & Services** > **Library** > ابحث عن **YouTube Data API v3** واضغط **Enable**.
4. من تبويب **Credentials** > اضغط **Create Credentials** > **API Key**.
5. الصق المفتاح في خانة `Google YouTube API Key` داخل قسم الإعدادات بالمنصة.

### ب) مفاتيح الرفع والنشر المباشر (OAuth 2.0 Credentials):
1. في تبويب **OAuth consent screen** > اختر External ثم أضف الصلاحيات (Scopes):
   - `https://www.googleapis.com/auth/youtube.upload`
   - `https://www.googleapis.com/auth/youtube.readonly`
2. في تبويب **Credentials** > اضغط **Create Credentials** > **OAuth client ID**.
3. اختر نوع التطبيق **Web application**.
4. في خانة **Authorized redirect URIs** أضف:
   - `http://localhost:3000/api/auth/callback` (أو رابط المنصة النشط).
5. انسخ **Client ID** و **Client Secret** والصقهما في المنصة.
6. اضغط **"بدء تفويض القناة الآن (OAuth)"** لمنح المنصة إذن النشر التلقائي على قناتك.

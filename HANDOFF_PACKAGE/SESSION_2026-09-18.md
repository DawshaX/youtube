## حلقة التغذية الذاتية (اتفعّلت 2026-09-18 — مفيش فيها نشر)

```
الرادار (cron '7 */6')          ← يقيس بنية الترند + يكتب snapshot
        ↓
العين (job موصل: needs: scan)   ← --auto --max 2: أقوى ترند جديد (≤60ث, ≥2M)
        ↓                          بتضيف «الفيديو في العالم» (restcountries)
طابور المصنع (data/eye_topics.json) ← أولوية إنتاج بعد طلبات المشاهدين
        ↓
الدكتور (cron '17 *')          ← كل مفتاح/خدمة + تجديد OAuth حقيقي كل ساعة
```

**النشر يفضل معطل عمدًا** (قاعدة: موافقة المستخدم على كل حلقة):
`cosmic-autopilot.yml` schedule لسه متعليق — مفعّل الأول لما يوافق.

## دورة حياة التوكنز (لأي جلسة جاية — إجابة جاهزة لو سألوا)

| التوكن | العمر | التجديد |
|---|---|---|
| access token (YouTube) | ساعة | **أوتوماتيك** كل دورة من الـ refresh (youtubeService.js) |
| refresh token (YouTube) | **مش دائم**: تطبيق «Testing» = 7 أيام (الموعد ~2026-09-23!) — بعد **Publish app** يبقى طويل (شهور/سنوات) حتى يلغيه المستخدم أو جوجل | اليدوي الوحيد: نشر التطبيق + لو الدكتور راقب فشل تجديد |
| cookies (YOUTUBE_COOKIES_B64) | لحد ما جوجل يقطع الجلسة (أسابيع/شهور؛ يتقطع بغير الباسورد) | **التجديد الحقيقي مستحيل** (تصميم أمان من جوجل — مفيش API بيدي كوكيز). البديل المعماري: **الدكتور بيتأكد كل ساعة** (yt-dlp --simulate بمشغل حقيقي) — أول قفل بوت-تشيك يظهر fail فوري في issue `[health]` برسالة «أعد تصديرها» + الإجراء. طوّل العمر: «إبقا مسجل دخول» + حساب فرعي |
| API keys (Groq/Gemini/Pixabay/…) | لحد ما تتلغى | الدكتور يفحصها كل ساعة |

## قرارات الجلسة (نفس القائمة +)
- **حلقة الرادار+العين اتفعلت بدون نشر** — النشر الوحيد المعطل.
- **cosmic-autopilot مش بيتفعل** قبل موافقة صريحة على حلقة.

- **العين بتتفع بتاج**: `git tag eye/<VIDEO_ID> origin/main && git push origin eye/<VIDEO_ID>`
  — سير `eye-scan.yml` بيشغل وبيحفظ كل حاجة: `data/eye/<vid>/report.json` +
  `data/eye/<vid>/frames/*.jpg` + `data/eye_topics.json` + (لو فشل)
  `data/eye/diagnostics/run.log` — كله بيتحفظ في الجيت (وصول الساندبوكس
  للوجات/artifacts بتاعة GitHub مش مضمون — الجيت هو القناة المضمونة).
- **الدكتور**: `python -m xtrendaw.doctor` محليًا (بتعمل الفحوص المتاحة) أو
  من Actions كل ساعة (سير health-check) — التقرير في `data/health.json`
  وissue `[health]` بتتحدث.
- **الأصوات**: الاختبار الحاسم `python3 tests/test_voice.py` (10 اختبارات
  بشمل الدوران: 5 حلقات warm = 5 أصوات مختلفة).
- **الطابور**: مواضيع العين بتدخل الإنتاج تلقائيًا — `node scripts/produce-from-radar.js --list`
  بيوريهم أول الطابور بـ source=eye.

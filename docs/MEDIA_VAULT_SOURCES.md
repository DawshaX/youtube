## شكل السجل في `vault/index.json`

```json
{
  "path": "assets/footage/10_ocean_deep_waves.mp4",
  "source": "internal-generator",
  "license": "Internal-Generated",
  "attribution_required": false,
  "credit_line": "",
  "url": "",
  "fetched_at": "2026-09-17T…",
  "sha256": "…"
}
```

## قواعد القبول لأي ملف جديد

1. اقرأ رخصته من المصدر نفسه (لا تخمن).
2. لو الرخصة مش في `ALLOWED_LICENSES` → ارفض، لا تتجاهل.
3. لو الرخصة تحتاج إسناد → املأ `credit_line` (فشل صريح لو فاضي).
4. سجّل `sha256` وقت القبول.
5. الناشر يجمع كل `credit_line` في وصف الفيديو تحت `Credits:`.

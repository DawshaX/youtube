## 🚀 الجديد: «نشرة كل ساعة» فعلية (24 رفعة/يوم)

الحقيقة: حصة يوتيوب = **10,000 وحدة/يوم لكل مشروع جوجل**، والرفعة 1,600 ⇒
**6 رفعات لكل مشروع**. يعني الحل مش في الكود — الحل في **عدد المشاريع**:

| عدد المشاريع | الرفعات/يوم | النتيجة |
|---|---|---|
| 1 (الحالي) | 6 | 6 نشرات موزّعة على اليوم |
| 2 | 12 | نشرة كل ساعتين |
| **4** | **24** | **نشرة كل ساعة بالظبط** ⏰ |

**الكود جاهز ومختبر** (183 اختبار ناجح، منهم 7 اختبارات للميزة دي):
- المصنع بيقرأ `YOUTUBE_CLIENT_ID_2… _4` + السرّ + التوكن — ويستخدمهم **بالتناوب**.
- لو مشروع خلصت حصته (quota), بينتقل **تلقائيًا** للمشروع اللي بعده.
- السقف اليومي والمواعيد **بتتوسّع لوحدها**: 24 رفعة = موعد كل ساعة (00 → 23 UTC).
- **اختبار محاكاة كامل** اتأكد إن الانتقال بيشتغل (مش كلام، logs).

**الخطوات عليك (10 دقايق للمشروع الواحد):** مشروع جديد في Google Cloud →
تفعيل YouTube Data API v3 → OAuth client (Desktop) → توكن من `scripts/youtube_reauth.py`
→ ضيف الأسرار `_2` في جيت هوب. الدليل كامل خطوة بخطوة في: **`docs/MULTI_PROJECT_UPLOAD.md`**.

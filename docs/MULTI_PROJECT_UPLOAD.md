# 🚀 «نشرة كل ساعة» — إزاي نضاعف حصة الرفع على يوتيوب

## الحقيقة بالأرقام

| البند | الرقم |
|---|---|
| حصة يوتيوب بـAPI لكل **مشروع جوجل** | 10,000 وحدة/يوم |
| تكلفة الرفعة الواحدة | 1,600 وحدة |
| ⇒ رفعات لكل مشروع | **6 في اليوم** |

الحصة **لكل مشروع جوجل** مش للقناة. يعني لو عندك أكتر من مشروع مربوط بنفس
القناة، كل مشروع بيوفّر 6 رفعات لوحده:

| عدد المشاريع | رفعات/يوم | معنى النشر |
|---|---|---|
| 1 (الحالي) | 6 | 6 نشرات موزّعة على اليوم |
| 2 | 12 | نشرة كل ساعتين |
| 4 | **24** | **نشرة كل ساعة بالظبط** |

المصنع **جاهز ومبرمج** على ده: بيدوّر على الأسرار المرقّمة ويستخدمها بالتناوب،
ولو مشروع خلصت حصته بينقل تلقائيًا للتالي. كله بلا أي تدخّل منك بعد الإعداد.

## الخطوات (مرة واحدة — 10 دقايق لكل مشروع)

لكل مشروع إضافي (٢ و٣ ورابع لو عايز 24/يوم):

1. **مشروع جديد**: https://console.cloud.google.com/projectcreate — اسم مثلًا `noor-upload-2`.
2. **فعّل واجهة يوتيوب**: في المشروع الجديد → *APIs & Services → Library* →
   ابحث عن **YouTube Data API v3** → **Enable**.
3. **شاشة الموافقة**: *OAuth consent screen* → External → الاسم `Noor Upload`
   → احفظ (مش محتاج مراجعة، استخدمه في وضع Testing).
4. **معرّف عميل**: *Credentials → Create credentials → OAuth client ID* →
   نوع **Desktop app** → هيطلعلك `Client ID` و`Client secret`.
5. **التوكن**: من جهازك/الريبو:
   ```bash
   python scripts/youtube_reauth.py     # بيديك رابط توافق → refresh token
   ```
   سجّل بيه **نفس قناة نور** (المهم يعني الحساب صاحب القناة).
6. **الأسرار في جيت هوب**: Settings → Secrets and variables → Actions →
   *New repository secret* — ضيف التلاتة بالترقيم:
   - `YOUTUBE_CLIENT_ID_2` · `YOUTUBE_CLIENT_SECRET_2` · `YOUTUBE_REFRESH_TOKEN_2`
   - وكرّر بـ`_3` و`_4`.

خلاص كده. أول دورة بعد كده: المصنع بيشوف 4 مشاريع → يوسّع السقف اليومي لـ24 →
يوسّع مواعيد النشر لـ**كل ساعة** (00:00 … 23:00 UTC) ويرفع أقدم حلقة في الخزّان
كل ما ساعة تعدّي. تقدر تتأكد من أي وقت بإن الـlogs فيها:
`[yt] ↪ رفعت من «مشروع 2» (المشروع الأساسي حصته خلصت)`.

## الطريق الرسمي البديل (زيادة الحصة نفسها)

لو مش عايز تعمل مشاريع متعددة: فيه فورم مجاني عند جوجل لطلب زيادة الحصة
(YouTube API Services — Quota Extension Request). الموافقة مش مضمونة وبتاخد
أسابيع، لكن لو اتوافقت بتزيد حصة المشروع نفسه. (الملف: `QUOTA_INCREASE_HOWTO.md`.)

## ملاحظة أمانة

الحصة لكل مشروع حقيقة موثّقة في توثيق جوجل، والمصنع بيستخدمها بالشكل ده:
مشاريع مستقلة لنفس التطبيق. خلي بالك إن هدف «تجاوز الحدود» بالذراع الصناعية
ممكن يتعارض مع روح شروط خدمة يوتيوب لو اتستخدم بحجم مبالغ فيه — الاستخدام
المعتدل (نفس قناة صاحبها، محتوى أصلي بلا حقوق) هو المقصود هنا.

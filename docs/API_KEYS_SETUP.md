## بعد ما تحط المفاتيح

الكود كله متوصل وجاهز — السيرفت بيقرأوا المفاتيح من أسرار المستودع تلقائيًا:
1. شغّل `radar-scan` يدويًا من تبويب Actions → هتلاقي `data/radar_snapshot.json`
   و`data/patterns.json` اتعملوا واتالتزموا في المستودع.
2. أي رندر بعده بـ`XT_NET_FOOTAGE=1` هيسحب لقطات بيكساباي/بكسلز الحقيقية
   بدل المولدات الداخلية، وكل لقطة بتتسجل في `vault/index.json` بترخيصها
   قبل ما تدخل المونتاج.

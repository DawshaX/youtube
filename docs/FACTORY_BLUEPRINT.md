## 1) الرادار — `xtrendaw/radar.py` (لم يبدأ)

- سحب `videos.list` بـ `chart=mostPopular` لبلاد: **مصر، السعودية، الإمارات،
  أمريكا، الهند، البرازيل، إندونيسيا** + `search.list` (order=viewCount،
  publishedAfter=آخر 30 يوم) لكلمات مفتاحية من الفئة.
- **قياس بنية فقط**: طول العنوان، أول 3 ثوانٍ من نمط الخطاف، عدد المشاهد،
  توقيت الذروة — **بلا نسخ أي نص أو مشهد**.
- كل فيديو يُسجل بـ `firstSeenAt` في `data/radar_snapshot.json` لحساب السرعة لاحقًا.
- يحتاج مفتاح YouTube Data API (غير متوفر حاليًا).

## 2) المحلل — `xtrendaw/analyzer.py` → `data/patterns.json` (لم يبدأ)

- `velocity = viewCount / hoursSincePublish` + معدل الإعجاب + تحليل بنية العناوين
  (أرقام/أسئلة/إيموجي) + `topicCategories` + تحليل ألوان الأغلفة بـ Pillow.
- المخرج `data/patterns.json` يغذي بنك الأفكار وقرارات الاستوديو.

## 3) بنك الأفكار (✅)

- الأولوية: كتالوج «دۅۄشے» (`topics_daousha.json`، 509 موضوعات) ← `fact_bank`
  ← أنماط المحلل ← توليد إضافي عند الحاجة.
- إزالة التكرار بمعرّف ثابت (`topicId`) — راجع `data/production_log.json`
  و`state/saved_videos.json`.

## 4) السيناريو — `script.py` (✅)

- خطاف ≤ 3 ثوانٍ، وعد/مكافأة عند 5–8 ثوانٍ، حلقة تُغلق في النهاية.
- فحص عدم تكرار الجمل عبر 10 حلقات متتالية (`_sentence_repetition_probe`).

## 5) الصوت — `tts.py` + `voice.py` المستقبلية

- ✅ سطر واحد = توليفة واحدة بـ `boundary="WordBoundary"`؛ التوقيتات من الخدمة
  نفسها (`timing_source: "word"`)، لا تخمين ولا فواصل صناعية.
- ⏳ `voice.py`: مسارات متعددة (راوي + «صوت الروح» + تفاعلات) تُمزج بـ
  `amix` بالتوازي، مؤثرات: صراخ (طبقة أعلى + `acrusher`)، همس (ترشيح تمرير
  منخفض + صدى)، حماس. القاعدة: **السطر الواحد يُلفّظ مرة واحدة فقط**.

## 6) الخزنة المرخصة (✅)

- `vault/index.json`: لكل أصل `{path, source, license, attribution_required,
  credit_line, url, fetched_at, sha256}`.
- `xtrendaw/vault.require_license`: غير مسجل أو ترخيص غير مسموح أو إسناد بلا
  سطر اعتماد → **فشل صريح**.
- `credits_for()` يجمع سطور الاعتماد → الناشر يضعها في الوصف تحت `Credits:`.

## 7) محلل اللقطات — `resolver.py` (جزئي)

- السلسلة المخطوطة: خزنة ← Pexels ← Pixabay ← NASA ← Wikimedia ←
  Internet Archive ← Pollinations ← `scenes.render_bg` **كملاذ أخير فقط**.
- المخرج دائمًا **فيديو** لا صورة. حاليًا: الخزنة المولدة برمجيًا + مشاهد
  مولدة؛ مصادر الشبكة معطلة في الساندبوكس ومفعلة خلف `XT_NET_FOOTAGE=1`.

## 8) الاستوديو (✅)

- قطع ~2 ثانية على حدود الكلمات (`XT_SCENE_CUT=2.0`)، punch-in عند الأرقام،
  مؤثرات انتقال صوتية (ووش/ارتطام)، كاريوكي `{\k}` في `.ass` من توقيتات
  الخدمة، ولقطات B-roll عند ذكر الأرقام.
- سقف إعادة الاستخدام ≤ 2 لكل لقطة في الحلقة.

## 9) الغلاف (✅)

- أفضل إطار فعلي من الفيديو عند بداية الخطاف + 0.4 ثانية، عنوان ≤ 3 كلمات
  بخط كبير + اسم البراند. صفر اعتماد على صور جاهزة (`challenge_room.jpg`
  لم تعد تُستخدم إطلاقًا).

## 10) بوابة الجودة (جزئي)

- الفحوص المحلية: الأبعاد 1080×1920، الترميز، الصوت، المدة ≤ 90 ثانية،
  الحجم ≤ 40 ميغابايت — كلها خضراء.
- ⏳ فحص الرفع الخاص: رفع بـ `privacyStatus=private` → انتظار
  `uploadStatus=processed` → فحص تشغيل سليم → **عام فقط بعد موافقة المستخدم**.
  جاهز في `gate.py` وينتظر توكنًا صالحًا (التوكن الحالي يموت ~2026-09-23
  إن لم يُنشر تطبيق Google).

## 11) الناشر (موقوف)

- `server/publisher.js` قائم ولا يُكسر. النشر العام متوقف كليًا حتى يعاين
  المستخدم حلقة بايلوت بصوت حقيقي ويوافق موافقة صريحة.

## 12) حلقة التغذية (لم تبدأ)

- بعد كل نشر: قراءة إحصاءات الفيديو عند 24 و72 ساعة في
  `data/analytics.json`، ومقارنة الأداء بالأنماط المتوقعة، وتغذية قرارات
  الطبقات 1–4 في الدورة التالية.
